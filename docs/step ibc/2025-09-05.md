# Progress IBC (Osmosis ICQ + Oracle + Fees) — 05 Sep 2025

Ringkasan progres hari ini, fokus ke “ICQ & relayer nyata” dengan bahasa sederhana.

## Inti hasil hari ini

- Aktifkan pendaftaran ICQ tanpa dep eksternal

  - Tambah client ICQ minimal via build tag `icq_register` (synthetic QueryID) supaya Keeper bisa mendaftarkan query TWAP/SPOT saat BeginBlock.
  - Wiring lewat depinject: saat build dengan tag tersebut, modul otomatis menyediakan `ICQClient` sederhana.

- Keeper mendaftarkan 2 query sekaligus (utama + cadangan)

  - Saat `UseTwap=true`, Keeper sekarang:
    - Mendaftarkan query TWAP (store `twap`).
    - Sekaligus mendaftarkan query SPOT/GAMM (store `gamm`) sebagai fallback.
  - QueryID keduanya disimpan di state (`QueryIDs["twap"], QueryIDs["spot"]`) dan muncul di AutoCLI status.

- Default params dipermudah untuk uji lokal

  - `connection_id = "connection-0"` (placeholder; ganti ke koneksi Osmosis nyata).
  - `pool_id = 1464` (contoh OSMO/USDC di Osmosis).
  - `base_denom = "uosmo"`, `quote_denom = "ibc/PLACEHOLDER_HASH"` (ganti ke hash USDC Osmosis riil).
  - `use_twap = true`, `twap_window_seconds = 300`.

- Dokumentasi & kebersihan repo
  - Tambah catatan build tags di docs: `icq_register` (pendaftaran query) dan `osmosis_real` (decoder Osmosis asli).
  - Netralisir skrip lama `docs/scripts/osmo-usdc-params.sh` (tidak dipakai lagi agar tidak membingungkan).
  - Update “Next steps prioritas” pada catatan 04 Sep sesuai rencana terbaru.

## Build & uji singkat (lokal)

- Build node dengan pendaftaran ICQ aktif: berhasil (binary: `build/cosviand-icq`).
- Uji kompilasi decoder Osmosis asli (`-tags osmosis_real`) pada paket keeper: berhasil.
- Catatan: Menjalankan node dengan `osmosis_real` bersama seluruh app saat ini dapat memicu konflik dependency IBC (v8 vs v10). Untuk saat ini, gunakan `osmosis_real` hanya di unit test; node cukup `icq_register` saja.

## Cara verifikasi (tanpa relayer dulu)

- Jalankan node hasil build `icq_register`.
- Cek AutoCLI:
  - `osmosisicq params` → tampilkan parameter modul.
  - `osmosisicq status` → pastikan ada `last_update`, `next_update`, dan map `queries` berisi `twap`/`spot` dengan QueryID.
- Bila QueryID belum muncul, pastikan:
  - `connection_id` tidak kosong, `pool_id > 0`, `base_denom/quote_denom` terisi, dan `update_interval_seconds` > 0.
  - Tunggu satu interval update atau kecilkan interval di params.

## Kendala yang dicatat

- Kombinasi build `osmosis_real` untuk seluruh node memicu benturan versi IBC (osmosis v30 menarik ibc-go v8, sedangkan app pakai ibc-go v10). Solusi: gunakan `osmosis_real` untuk test decoder saja, dan rencanakan isolasi/adapter jika ingin menjalankan penuh di node.
