# Progress IBC (Band + Oracle + Fees) — 03 Sep 2025

Ringkasan progres dari awal implementasi draft plan sampai update terakhir, dengan bahasa yang mudah.

Tujuan:

- Memakai IBC untuk ambil harga USD realtime dan memakainya di modul fees (konversi USD → ucsv) via oracle chain internal.
- Desain multi-sumber: Osmosis (pool USDC), Band Protocol (IBC), CoinGecko, dengan fallback Last Good Price (LGP).

Langkah dari awal sampai sekarang:

1. Analisis kodebase & rancangan

- Mapping modul terkait: `x/pricefeed` (IBC app), `x/oracle` (sumber kebenaran harga), `x/fees` (butuh CSV per USD).
- Menulis dan merevisi dokumen rencana: `docs/ibc-live-usd-plan.md` dan `docs/IBC implementation draft.md` (multi-sumber + LGP, TWAP, governance, testing).

2. Implementasi awal (Band lebih dulu)

- Wiring `pricefeed → oracle`: saat menerima paket response dari Band, simpan nilai CSV/USD ke `x/oracle`.
- Perbaikan logika parsing harga: prioritas `Rates` (CSV per USD). Jika hanya dapat `Prices` (USD per CSV), dibalik (1/x) jadi CSV/USD.
- Tambah unit test untuk `ProcessPriceResponse` (happy path Rates dan path pembalikan dari Prices).

3. IBC routing & port binding

- Route IBC `pricefeed` sudah terpasang di `app/ibc.go`.
- Sempat mencoba bind port manual seperti versi lama; setelah cek ibc-go v10, bind manual via capability tidak diperlukan. Perubahan PortKeeper dibatalkan dan kode dibersihkan.

4. Relayer & channel

- Tambah panduan singkat relayer: `docs/relayer-pricefeed-band.md` (buka channel UNORDERED dengan version `pricefeed-1`).

5. Verifikasi penyimpanan harga
